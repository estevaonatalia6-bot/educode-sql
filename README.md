# EduCode — Banco de Dados / SQL

Repositório de dados do **EduCode**, sistema de gestão educacional para instituições de pequeno e médio porte.

## Sobre o Projeto

O EduCode é uma plataforma digital desenvolvida no contexto do Projeto Integrador do curso de Engenharia de Software da UniEVANGÉLICA. O sistema tem como objetivo modernizar a administração de instituições de ensino, substituindo processos manuais e fragmentados por um ambiente integrado para controle de matrículas, frequência, comunicação institucional e geração de relatórios.

Este repositório foi criado durante o 2º período (Fase 02) para abrigar os artefatos relacionados ao banco de dados do projeto.

## Situação Atual

Neste momento o repositório **não possui código SQL**. A criação dos scripts (modelagem, criação de tabelas, consultas e carga de dados) está **prevista para as próximas fases** do Projeto Integrador, conforme as diretrizes da disciplina.

## Conteúdo Previsto

- Scripts de criação do banco de dados e das tabelas
- Scripts de inserção de dados de exemplo
- Consultas e relatórios
- Documentação do modelo de dados
